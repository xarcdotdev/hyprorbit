## [0.2.2] - 2026-11-19

### Fixed
- Monitors connected after startup (docking, hotplug) are switched from Hyprland's numbered default workspace to an unused module workspace of the active orbit.
- Workspace reset on multiple monitors no longer leaves a monitor on a numbered workspace when its preferred module workspace is owned by another monitor.

## [0.2.1] - 2026-11-13

### Fixed
- Workspace reset no longer leaves a numbered workspace (e.g. `3`) on a secondary monitor; windows are now moved by address instead of being focused first, which made Hyprland re-show their hidden workspace.
- Long-running daemon requests (workspace reset, `window move all --global`) no longer fail with `ipc: decode response: EOF`; the 500 ms IPC deadline now only bounds socket I/O, not request handling.

## [0.2.0] - 2026-09-15

### Breaking Changes
- Workspace reset and temporary cleanup no longer force-delete workspaces; Hyprland-retained workspaces remain and are reported.

### Added
- Automatic compatibility with Hyprland 0.56's Lua dispatch interface while retaining legacy dispatch support.

### Fixed
- Validate dispatch responses and batch framing so compositor failures are returned instead of treated as success.
- Reconcile temporary workspace registrations only after compositor-confirmed removal, including partial reset failures.

## [0.1.2] - 2026-10-20

### Breaking Changes
- Changed workspace names from `<module>-<orbit>` to `<orbit>-<module>`, including temporary workspaces.

### Added
- Added Waybar setup documentation and an example configuration.
- Updated the configuration generated by `hyprorbit init` with current focus, orbit cycling, and debug settings.

### Fixed
- Corrected invalid YAML entries, indentation, and characters in the generated and documented configuration.
